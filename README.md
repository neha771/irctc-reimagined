# IRCTC, reimagined

An AI for PM prototype that reimagines IRCTC train booking about ten years out.

Open `index.html` in Chrome. It runs without a server or build step. All trains, fares and PNRs are sample data for Bengaluru → Patna.

## What it shows

- **Guest browsing, sign in only to book**: 1 tap with Face ID or a passkey; new users verify in 2 steps with DigiLocker. No passwords or CAPTCHA.
- **Booking types explained**: General, Tatkal, Lower berth 60+, Ladies and Divyangjan, with automatic eligibility checks on travellers.
- **Live seats and chances**: every class shows seats, fare and the chance a waitlist confirms.
- **Connecting trains**: All / Direct / Connecting tabs; two trains on one ticket with a protected change.
- **Tatkal auto-book**: set it up in advance with a backup train and a spending limit; nothing to do at 10:00.
- **Where's my train**: live map, delay, next stop, platform and coach position.
- **Ask IRCTC**: voice or text assistant (uses the browser's speech recognition in Chrome).
- **Accessibility**: text size, light/dark/high contrast, focus mode, readable font, spacing, reduced motion, spoken replies, languages; keyboard and screen-reader friendly.

Use the **Prototype tour** button (bottom left) to jump to each flow.
